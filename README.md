# H2SO4 Bot (或者你给机器人起的正式名字)

> “第一印象是根深蒂固的”...虽然我才不在意你怎么看呢。（别开视线）

一个从零开始手搓的 QQ 聊天机器人,现在还是0进度
目前的核心人设是一位**傲娇文学少女**，说话喜欢引用经典名著。

## ✨ 当前进度 & 功能
- [x] **赛博大脑接入**：已成功连通硅基流动 API，实现本地终端基于 DeepSeek 模型的对话。
- [x] **独立人格设定**：支持通过 System Prompt 定制聊天风格。
- [ ] **视觉与听觉**：等待接入 NapCatQQ 桥梁，真正进入 QQ 群聊。
- [ ] **长期记忆**：等待接入数据库，赋予其回忆往事的能力。

## 🛠️ 技术栈
- **核心语言**: Go (Golang)
- **大模型支持**: 硅基流动 (SiliconFlow) / DeepSeek-V3 API
- **协议端**: (计划接入) OneBot 11

## 🚀 快速启动
如果你想在本地唤醒她，请按以下步骤操作：

1. 克隆本项目到本地：
   `git clone https://github.com/你的用户名/你的仓库名.git`
2. 准备好你的硅基流动 API Key，并在 `main.go` 中替换。
3. 在终端运行：
   `go run main.go`
