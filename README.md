# H2SO4 Bot 

> “第一印象是根深蒂固的”...虽然我才不在意你怎么看呢。（别开视线）

一个从零开始手搓的 QQ 聊天机器人,现在大体依旧是0进度
目前的人设是一位**傲娇文学少女**，说话喜欢引用经典名著。

## ✨ 当前进度 & 功能
- [x] **赛博大脑接入**：已成功连通硅基流动 API，实现本地终端基于 DeepSeek 模型的对话。
- [x] **独立人格设定**：支持通过 System Prompt 定制聊天风格。
- [x] **视觉与听觉**：已接入 NapCatQQ 桥梁，尝试进入 QQ 群聊。
- [x] **长期记忆**：等待接入数据库，赋予其回忆往事的能力。

目前main.go有点太冗长了。感觉得单独弄一页来完善机器人的机制。
## 🛠️ 技术栈
- **核心语言**: Go (Golang)
- **大模型支持**: 硅基流动 (SiliconFlow) / DeepSeek-V3 API
- **协议端**: (计划接入) OneBot 11

## 🚀 快速启动
目前只支持本地启动。如果你想唤醒她，请按以下步骤操作：

1. 克隆本项目到本地：
   `git clone https://github.com/你的用户名/你的仓库名.git`
2. 准备好你的硅基流动 API Key，并在 `.env` 中替换。
3. 在终端运行：
   `go run main.go`
